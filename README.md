# Cyclo Manager — pages légales

Pages publiques (GitHub Pages) de Cyclo Manager : politique de confidentialité et fiche Data safety,
en français (`privacy.html`, `data-safety.html`) et en anglais (`privacy-en.html`, `data-safety-en.html`).
La page française renvoie un navigateur non francophone vers l'anglais : une seule URL suffit dans la Play Console.

Copie de `public/legal/` du dépôt du jeu, générée par `npm run legal:pages` depuis `src/legal/documents.ts`
et `documentsEn.ts` ; à resynchroniser quand les textes changent.
