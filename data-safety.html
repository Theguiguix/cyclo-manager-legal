Fiche Data safety

Mise à jour : 26 octobre 2026

Cette fiche reprend, en langage clair, les déclarations prévues par le formulaire Data safety de Google Play. Elle décrit ce que l’app et ses SDK partenaires font — pas un recueil de données sur nos serveurs (il n’y en a pas).

Vue d’ensemble

Collecte : aucune donnée envoyée à un serveur Cyclo Manager. Des données sont collectées par les SDK Google intégrés : AdMob (publicités) et Google Analytics for Firebase (mesure d’audience anonyme, avec consentement dans l’EEE / UK / Suisse).

Partage : oui, uniquement via Google AdMob (publicités) pour les joueurs sans pass, lorsque le réseau est disponible et le consentement le permet. Firebase agit comme sous-traitant : ses données ne sont pas partagées avec des tiers.

Vente de données par l’éditeur : non. Chiffrement en transit : oui, toutes les données collectées passent par HTTPS (l’app n’a aucun appel réseau propre). Suppression : oui (sauvegarde locale + désinstallation + demande par e-mail).

Public visé : 16 ans et plus. L’app ne s’adresse pas aux enfants.

Données collectées — Identifiants de l’appareil

Identifiant publicitaire Android (permission AD_ID) : utilisé par Google AdMob pour diffuser et mesurer des publicités. Pas stocké par Cyclo Manager. Peut être réinitialisé dans les réglages du téléphone.

Finalité : publicité. Optionnel : oui (pass sans pub, hors ligne, ou refus de consentement selon le message UMP).

Identifiant d’installation Firebase (app instance ID) : propre à l’application, sans lien avec l’identifiant publicitaire, réinitialisé à la désinstallation. Finalité : statistiques (analytics). Collecté, non partagé.

Données collectées — Informations financières

Historique d’achat in-app : traité par Google Play (pass sans publicité). Cyclo Manager ne reçoit que le statut d’achat / restauration, et enregistre localement « pass actif ».

Finalité : traitement de l’achat. Données bancaires : jamais lues par l’app.

Données collectées — Activité dans l’app

Interactions avec les annonces (affichage, fermeture) : traitées par AdMob pour la diffusion. Finalité : publicité. Absent si pass / hors ligne / course d’essai (pas d’interstitiel).

Interactions avec l’app : 8 événements de jeu anonymes envoyés à Google Analytics for Firebase (carrière lancée, course d’essai, première course officielle, saison terminée, montée ou descente, faillite, pub récompensée regardée, réponse aux notifications). Ni nom, ni nom de club, ni e-mail. Finalité : statistiques (analytics). Collecté, non partagé, optionnel dans l’EEE / UK / Suisse (refus dans le message de consentement).

Notifications : locales, programmées sur l’appareil, aucune donnée envoyée.

Données non collectées

Position précise, contacts, photos, fichiers, SMS, calendrier, santé, audio, journal d’appels, nom réel, e-mail, liste d’apps, diagnostics / crash envoyés par l’éditeur (les SDK Google Play et AdMob peuvent en traiter de leur côté, voir plus haut).

Sécurité

La partie reste sur l’appareil. Les échanges AdMob, Firebase et Play Billing passent par HTTPS. L’éditeur ne transmet pas la sauvegarde vers le cloud.

Engagement « Independent security review » : non (jeu indie, pas d’audit externe déclaré).

Comment supprimer les données

Sauvegarde de carrière : Paramètres → Carrière → Quitter ce club, ou désinstallation.

Mesure d’audience : désinstaller l’app réinitialise l’identifiant Firebase ; une demande d’effacement peut être envoyée à Contact_GT.Solutions@proton.me.

Identifiant pub : Réglages Android → Confidentialité / Google → Réinitialiser l’identifiant publicitaire.

Achats : gérés par Google Play (historique du compte). Le pass peut être restauré sur un autre appareil via « Restaurer un achat ».
