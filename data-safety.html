Fiche Data safety

Mise à jour : 2 septembre 2026

Cette fiche reprend, en langage clair, les déclarations prévues par le formulaire Data safety de Google Play. Elle décrit ce que l’app et ses SDK partenaires font — pas un recueil de données sur nos serveurs (il n’y en a pas).

Vue d’ensemble Play Console

Collecte par l’éditeur : aucune donnée envoyée à un serveur Cyclo Manager.

Partage : oui, uniquement via Google AdMob (publicités) pour les joueurs sans pass, lorsque le réseau est disponible et le consentement le permet.

Vente de données par l’éditeur : non. Chiffrement en transit : oui pour les appels pubs / Play. Suppression : oui (sauvegarde locale + désinstallation).

Données collectées — Identifiants de l’appareil

Identifiant publicitaire Android (permission AD_ID) : utilisé par Google AdMob pour diffuser et mesurer des publicités. Pas stocké par Cyclo Manager. Peut être réinitialisé dans les réglages du téléphone.

Finalité : publicité. Optionnel : oui (pass sans pub, hors ligne, ou refus de consentement selon le message UMP).

Données collectées — Informations financières

Historique d’achat in-app : traité par Google Play (pass sans publicité). Cyclo Manager ne reçoit que le statut d’achat / restauration, et enregistre localement « pass actif ».

Finalité : traitement de l’achat. Données bancaires : jamais lues par l’app.

Données collectées — Activité dans l’app (SDK pubs)

Interactions avec les annonces (affichage, fermeture) : traitées par AdMob pour la diffusion. Pas d’analytique produit (pas de Firebase Analytics, pas de suivi de carrière hors appareil).

Finalité : publicité. Absent si pass / hors ligne / course d’essai (pas d’interstitiel).

Données non collectées

Position, contacts, photos, fichiers, SMS, calendrier, santé, audio, journal d’appels, données de santé, nom réel, e-mail, liste d’apps, diagnostics / crash envoyés par l’éditeur.

Sécurité

La partie reste sur l’appareil. Les échanges pubs et Play Billing passent par HTTPS. L’éditeur ne transmet pas la sauvegarde vers le cloud.

Engagement « Independent security review » : non (jeu indie, pas d’audit externe déclaré).

Comment supprimer les données

Sauvegarde de carrière : Paramètres → Carrière → Quitter / nouvelle carrière, ou désinstallation.

Identifiant pub : Réglages Android → Confidentialité / Google → Réinitialiser l’identifiant publicitaire.

Achats : gérés par Google Play (historique du compte). Le pass peut être restauré sur un autre appareil via « Restaurer un achat » une fois Play Billing branché.

À reporter dans Play Console

Data types : Device or other IDs (advertising ID) — collected and shared by AdMob, not by us. App activity related to ads — AdMob. In-app purchases — Play Billing.

Is this app required to have a privacy policy? Oui. Users can request data deletion? Oui (locale + Android ads ID). Data encrypted in transit? Oui (SDK Google).
